# D3ST: Stellar Industries

**Planet Clicker Idle Game** - Klikej na planety, sbírej zdroje a upgraduj!

## Features

🌍 **6 Planet** - Interaktivní planety s různými tématy
⚙️ **Upgrade Systém** - Double Click, Auto Clicker, Planet Power
🏆 **Achievements** - Odemykej během hry
✨ **Prestiž** - Resetuj a získej bonus
💾 **Auto-Save** - Hra se sama ukládá

## Jak hrát

1. Klikej na planety a sbírej zdroje
2. Kupuj upgrades za zdroje
3. Odemykej achievements
4. Resetuj pomocí prestiže a získej bonus na začátek

## Jak spustit

1. Stáhni [Godot Engine 4.x](https://godotengine.org/)
2. Otevři projekt v Godotu
3. Spusť hru: `F5` nebo klikni ▶

Příjemnou hru! 🚀
